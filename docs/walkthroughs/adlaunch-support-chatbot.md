# AdLaunch Support - Votre Nouvel Assistant Intelligent

Nous avons ajouté un chatbot de support client premium à l'ensemble de la plateforme AdLaunch Pro pour offrir une assistance instantanée à vos utilisateurs.

## Fonctionnalités Clés

### 1. Interface Premium
- **Widget Flottant** : Une icône non intrusive en bas à droite de l'écran.
- **Design Moderne** : Utilisation d'effets de flou (glassmorphism), d'ombres douces et d'animations fluides.
- **Responsive** : Parfaitement adapté aux mobiles et tablettes.

### 2. Intelligence Automatisée
- **Réponses Instantanées** : Le chatbot répond immédiatement aux questions courantes (Prix, Facebook, Aide, etc.).
- **Boutons de Réponse Rapide** : Guidage de l'utilisateur avec des suggestions de questions fréquentes.
- **Simulation Réaliste** : Un indicateur de frappe ("en train d'écrire...") pour une expérience plus humaine.

### 3. Intégration Complète
Le chatbot est actif sur toutes les pages critiques :
- **Page d'Accueil** (`index.html`) : Pour convertir les prospects.
- **Tableau de Bord** (`dashboard.html`) : Pour aider les utilisateurs lors de la création de campagnes.
- **Administration** (`admin.html`) : Pour assister les administrateurs.

## Comment l'utiliser ?

1.  Cliquez sur l'icône de message 💬 en bas à droite de n'importe quelle page.
2.  Posez une question comme *"Quels sont les tarifs ?"* ou *"Comment connecter Facebook ?"*.
3.  Utilisez les boutons de réponse rapide pour découvrir les fonctionnalités.
