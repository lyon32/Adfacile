```
## ✅ COMMENT ACTIVER LE DÉPLOIEMENT AUTOMATIQUE

### **ÉTAPE 1 : Connecte ton projet GitHub à Vercel**

1. **Va sur** https://vercel.com/lionelyvan24-7938s-projects/adsfacile/settings/git

2. **Clique** "Connect Git Repository"

3. **Choisis** ton repo GitHub : `lionelyvan24/Adfacile` (ou le nom exact)

4. **Configure :**
```
   Production Branch: main (ou master)
   Root Directory: frontend
Save
